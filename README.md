# Blood Bank Management System

A web-based Blood Bank Management System developed using PHP and MySQL. This project helps users register, donate blood, request blood, and allows admin to manage donor and request records.

## Features

- User Registration
- User Login
- Blood Donation Form
- Blood Request Form
- Admin Panel
- Donor Approval and Rejection
- Blood Request Approval and Rejection
- MySQL Database Integration

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP
- Git
- GitHub

## Project Modules

### User Module
- Register
- Login
- Donate Blood
- Request Blood

### Admin Module
- View donor details
- Approve or reject donor records
- View blood request details
- Approve or reject blood requests

## How to Run This Project

1. Install XAMPP.
2. Start Apache and MySQL from XAMPP Control Panel.
3. Copy the project folder into:

C:\xampp\htdocs\

4. Open phpMyAdmin:

http://localhost/phpmyadmin

5. Create a database named:

blood_bank_db

6. Import the SQL file.
7. Open the project in browser:

http://localhost/blood-bank-management-system/
